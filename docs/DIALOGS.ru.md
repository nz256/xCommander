# Система интерактивных TUI-диалогов `xCommander` (`-D` / `--dialog` и `:dialog`)

## 1. Общая идея и архитектура

В `xCommander` встроена единая подсистема интерактивных диалоговых окон, работающая **двумя способами**:
1. **Снаружи (из терминала и bash/python-скриптов)** — через флаг **`xc -D`** (`--dialog`).
2. **Изнутри запущенного `xCommander`** — через встроенную команду **`:dialog`** (`:D`) из командной строки, экрана терминала (`Ctrl+O`), пользовательского меню (`F2`), истории команд (`Alt+F8`) и пакетного запуска (`Ctrl+G`).

### Ключевые особенности
* **Прозрачный ANSI-оверлей через `/dev/tty`**: без флага `--bg` окно рисуется поверх текущего вывода терминала без очистки экрана, а после закрытия экран и курсор полностью восстанавливаются.
* **Чистый `stdout` для `$(...)`**: весь TUI-интерфейс в оверлее идёт напрямую в `/dev/tty`, поэтому `VAR=$(xc -D input ...)` и `CH=$(xc -D menu ...)` захватывают только введённый текст или выбранный пункт.
* **Нативное выполнение внутри `xc`**: `:dialog` / `:D` рисуется поверх панелей в текущем процессе без запуска дочернего `xc`.
* **Фон `--bg <цвет>`**: поддержка имён цветов (`darkblue`, `black`, `cyan` и др.), индексов `0..255` и HEX-цветов (`#RRGGBB`).

## 2. Внешний CLI-режим: `xc -D` / `xc --dialog`

```bash
xc -D [--bg <цвет>] <подкоманда> [аргументы...]
```

### 2.1. `msg` — Информационное окно (по умолчанию)
Прокрутка: `Up`/`Down`, `PgUp`/`PgDn`, колесо мыши. Закрытие: `Enter`, `Esc`, `Space`, `E` или клик по `{ Enter }`.
```bash
xc -D "Готово" "Резервная копия создана.\nОшибок нет."
git status -s | xc -D "Статус Git" -
xc -D --bg "#1e1e2e" msg "Релиз" "Сборка завершена"
```

### 2.2. `confirm` — Окно подтверждения (`Yes` / `No`)
Кнопки `{ Yes }` и `[ No ]`. Управление: `Left`/`Right`, `Tab`, `Y`/`N`, `Enter`, `Esc`, мышь. Возвращает `0` (`Yes`) или `1` (`No`/`Esc`).
```bash
xc -D confirm "Деплой" "Отправить изменения на сервер?" && git push
```

### 2.3. `input` — Поле ввода UTF-8
Поддерживает выделение (`Shift+Стрелки`, `Ctrl+A`), переход по словам (`Ctrl+Left`/`Right`) и буфер обмена (`Ctrl+C`, `Ctrl+X`, `Ctrl+V`). Печатает ввод в `stdout`, возвращает `0` (`OK`) или `1` (`Cancel`/`Esc`).
```bash
MSG=$(xc -D input "Git Commit" "Введите сообщение:") && git commit -m "$MSG"
BRANCH=$(xc -D input "Ветка" "Имя ветки:" "feat/") && git checkout -b "$BRANCH"
```

### 2.4. `menu` — Меню выбора из списка
Навигация: `Up`/`Down`, `PgUp`/`PgDn`, `Home`/`End`, колесо и клик мыши. Печатает выбранный пункт в `stdout`, возвращает `0` (`Enter`/клик) или `1` (`Esc`).
```bash
ENV=$(xc -D menu "Окружение" "dev" "staging" "prod") && echo "Среда: $ENV"
BRANCH=$(git branch --format='%(refname:short)' | xc -D menu "Ветка" -) && git checkout "$BRANCH"
```

### 2.5. `form` — Запуск диалога из файла сценария (или `stdin`)
Файл сценария может иметь любое имя (например, `deploy.dialog`):
```ini
type=confirm           # msg | confirm | input | menu
title=Деплой проекта
bg=#1e1e2e             # необязательный цвет фона
text=Отправить сборку на сервер?\nВсе сервисы будут перезапущены.
default=feat/new       # начальное значение для type=input
items=dev|staging|prod # пункты через '|' для type=menu
```
Запуск: `xc -D form deploy.dialog && ./deploy.sh` или `cat deploy.dialog | xc -D form -`.

## 3. Встроенный режим внутри `xCommander`: `:dialog` и `:D`

Вызывается из командной строки, `Ctrl+O`, пользовательского меню **`F2`**, истории **`Alt+F8`** и **`Ctrl+G`** без запуска дочернего процесса `xc`:
```text
:dialog "Заголовок" "Текст сообщения"
:D DIALOGS.ru.md
:dialog confirm "Вопрос" "Продолжить?"
:dialog input "Заголовок" "Подсказка" "По умолчанию"
:dialog menu "Выбор" "Пункт 1" "Пункт 2" "Пункт 3"
:dialog form /путь/к/файлу.dialog
```

### Подстановки `$(:dialog ...)` и цепочки `&&` (в `F2` и командной строке)
```ini
c:	Git Commit | MSG=$(:dialog input "Git Commit" "Сообщение:") && git commit -m "$MSG"
d:	Deploy Confirm | :dialog confirm "Деплой" "Отправить изменения?" && git push
t:	Test Chain | VAL=$(:dialog input "Ввод" "Имя:" "test") && :dialog "Результат" "Введено: $VAL"
```
* `$(:dialog input ...)` и `$(:dialog menu ...)` разворачиваются прямо поверх панелей; при нажатии `Esc` / `Cancel` цепочка прерывается.
* Присваивания `VAR=значение` в цепочке `&&` сохраняются в окружение и подставляются как `$VAR` / `${VAR}` в последующие команды.
* При одиночном вызове `:dialog input ...` или `:dialog menu ...` введённое или выбранное значение автоматически сохраняется в переменную окружения **`$XC_DIALOG_OUT`**, поэтому его можно использовать в следующих командах и пунктах меню `F2` (например: `:dialog "Результат" "Выбрано: $XC_DIALOG_OUT"` или `echo "$XC_DIALOG_OUT"`).
* В `Ctrl+G` работают FAR-макросы: `:dialog "Файл" "Имя: !.!\nКаталог: !/"`.
