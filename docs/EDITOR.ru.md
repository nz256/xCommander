# Встроенный TUI-редактор `xCommander` (`F4` / `xc -e`)

## 1. Способы запуска

Встроенный полноэкранный текстовый редактор работает как изнутри файлового менеджера, так и как самостоятельный консольный редактор:

* **Из панелей `xCommander`**:
  * `F4` — открыть файл под курсором (если курсор внутри архива `.zip` / `.tar.*` / `.7z`, файл автоматически извлекается, редактируется и при сохранении обновляется внутри архива).
  * `Shift+F4` — создать новый файл с вводом имени и сразу открыть его в редакторе.
  * `Alt+F9` — история открытых файлов (512 записей с сохранением точной строки и столбца курсора).
  * `Shift+Enter` в командной строке — выполнить команду и открыть её вывод в редакторе.
* **Из терминала и скриптов (`xc -e` / `xc --edit`)**:
  ```bash
  xc -e file.c                 # открыть файл
  xc -e 42 file.c              # открыть файл и перейти на строку 42
  xc -e 42:15 file.c           # открыть файл на строке 42, столбце 15
  git diff | xc -e -           # открыть вывод stdin во временном буфере редактора
  ```

## 2. Подсветка синтаксиса и режимы отображения

Редактор автоматически определяет язык по расширению файла и подсвечивает ключевые слова, строки, числа, комментарии (`//`, `/* ... */`, `#`) и директивы препроцессора:

| Профиль языка | Поддерживаемые расширения | Особенности |
| :--- | :--- | :--- |
| **C / C++** | `.c`, `.h`, `.cpp`, `.hpp`, `.cc` | Ключевые слова C/C++, `#include`/`#define`, `//` и многострочные `/* ... */` |
| **Python** | `.py`, `.pyw` | Ключевые слова Python 3, строки, числа, комментарии `#` |
| **Shell** | `.sh`, `.bash`, `.zsh` | Конструкции `if`/`then`/`fi`, `for`, `case`, встроенные команды, `#` |
| **Config** | `.conf`, `.ini`, `.cfg`, `.toml`, `.yaml`, `.yml`, `.env` | Ключевые слова состояния (`TRUE`/`FALSE`, `YES`/`NO`, `TODO`, `FIXME`, `ERROR`), `#` |

* **`F4`** (внутри редактора) — включить / выключить подсветку синтаксиса.
* **`F5`** — включить / выключить отображение невидимых символов (пробелы `·`, табуляции `→`, переводы строк).
* **`Insert`** — переключение режимов вставки (`INS`) и замены (`OVR`).
* **`F9`** — переключение авто-отступа при нажатии `Enter` (`Ind:On` / `Ind:Of`).

## 3. Навигация, парные скобки и выделение текста

### Перемещение курсора и мышь
* **Стрелки / `Home` / `End`** — посимвольно, по строкам, в начало/конец текущей строки.
* **`Ctrl+Left` / `Ctrl+Right`** — прыжки по словам.
* **`Ctrl+Home` / `Ctrl+End`** — в начало / конец всего файла.
* **`PageUp` / `PageDown`** — прокрутка на экран вверх / вниз.
* **`Alt+F8`** — переход к указанной строке или позиции `СТРОКА[:СТОЛБЕЦ]`.
* **`Ctrl+]`** — прыжок на парную скобку или кавычку (`()`, `[]`, `{}`, `""`, `''`).
* **Мышь** — клик ставит курсор в нужное место, колесо прокручивает текст, клик по нижней панели `F1..F12` вызывает соответствующую функцию.

### Выделение блоков и системный буфер обмена
* **`Shift+Стрелки` / `Shift+Home` / `Shift+End`** — выделение символов, строк, до начала/конца строки.
* **`Ctrl+Shift+Стрелки`** (или `Alt+Shift+Стрелки`) — выделение целыми словами.
* **`Ctrl+Shift+Home` / `Ctrl+Shift+End`** — выделение от курсора до начала / конца файла.
* **`F3`** — режим пометки `MARK` (перемещение курсора расширяет выделение без удержания `Shift`).
* **`Alt+Shift+]`** — выделить содержимое внутри парных скобок/кавычек (повторное нажатие расширяет выделение на сами скобки/кавычки; выбирается ближайшая внутренняя пара).
* **`Ctrl+A`** — выделить весь файл.
* **`Ctrl+C` / `Ctrl+X` / `Ctrl+V` (`Shift+Ins`)** — копировать, вырезать (блок или текущую строку) и вставить (поддерживается многострочная вставка из системного буфера X11/Wayland).

## 4. Редактирование строк, блоков и Undo / Redo

* **`Tab` / `Shift+Tab`** — вставить отступ или сдвинуть выделенный блок вправо / влево.
* **`Ctrl+Shift+D`** — дублировать текущую строку или выделенный блок.
* **`Ctrl+/`** — закомментировать / раскомментировать текущую строку или выделенный блок (автоматически использует `//` или `#` в зависимости от языка).
* **`Ctrl+Shift+Up` / `Ctrl+Shift+Down`** — переместить текущую строку или выделенный блок вверх / вниз.
* **`Ctrl+Y`** — удалить всю текущую строку.
* **`Alt+Backspace`** — удалить слово слева от курсора.
* **`Ctrl+Z` / `Ctrl+R`** — отмена (`Undo`) и повтор (`Redo`) изменений (история до **64 шагов**).

## 5. Поиск и интерактивная замена (включая RegExp)

* **`F7`** — поиск текста с параметрами:
  * **`[ ] Case sensitive`** — поиск с учётом регистра (по умолчанию регистр не учитывается, включая кириллицу);
  * **`[ ] RegExp`** — включить встроенный многострочный движок регулярных выражений с поддержкой UTF-8.
* **`Shift+F7`** — найти следующее совпадение.
* **`Ctrl+F7`** — интерактивный поиск и замена с предпросмотром подстановки и пошаговым подтверждением:
  * **`Replace`** — заменить текущее совпадение и перейти к следующему;
  * **`All`** — заменить все оставшиеся совпадения в файле без подтверждения (отменяется одним нажатием `Ctrl+Z`);
  * **`Skip`** — пропустить текущее совпадение;
  * **`Cancel` (`Esc`)** — остановить замену.

### 5.1. Синтаксис регулярных выражений в поле «Поиск» (`RegExp`)

| Конструкция | Что означает | Пример шаблона |
| :--- | :--- | :--- |
| `.` | Любой символ, кроме перевода строки `\n` | `a.c` (`abc`, `a1c`) |
| `\d` / `\D` | Цифра `0..9` / любая не-цифра | `\d+` (целое число) |
| `\w` / `\W` | Буква (включая кириллицу), цифра или `_` / не-слово | `\w+` (идентификатор или слово) |
| `\s` / `\S` | Пробел или табуляция `\t` / непробельный символ | `\s+` (любые пробелы/табы) |
| `^` / `$` | Начало строки / конец строки | `^#.*$` (строка-комментарий) |
| `\n`, `\t` | Перевод строки (многострочный поиск!) и табуляция | `\n\n+` (пустые строки подряд) |
| `*`, `+`, `?` | Жадные квантификаторы: `0+`, `1+`, `0..1` | `".*"` (от первой до последней `"`) |
| `*?`, `+?`, `??` | Ленивые квантификаторы (до первого совпадения) | `".*?"` (каждая строка в кавычках отдельно) |
| `(...)` | Группа захвата (до **9** групп на шаблон) | `(\w+)\s*=\s*(.+)` |
| `\.`, `\(`, `\)` | Экранирование спецсимволов (`.`, `(`, `)`, `*`, `+`, `?`, `^`, `$`, `\`) | `func\((.*?)\)` |

### 5.2. Спецсимволы и группы захвата в поле «Замена»

| Подстановка | Что вставляет при замене |
| :--- | :--- |
| `\0` | Весь найденный фрагмент целиком |
| `\1` .. `\9` | Текст, захваченный соответствующими круглыми скобками `(...)` |
| `\t` | Символ табуляции |
| `\n` | Перевод строки (разбивает одну найденную строку на несколько строк!) |
| `\\` | Обычный обратный слэш `\` |

### 5.3. Практические примеры для `Ctrl+F7` (с галочкой `RegExp`)

1. **Поменять местами левую и правую части присваивания (`a = b` -> `b = a`)**:
   * Поиск: `^(\s*)(\w+)\s*=\s*(.+)$`
   * Замена: `\1\3 = \2`
2. **Удалить лишние пробелы и табуляции в конце всех строк**:
   * Поиск: `\s+$`
   * Замена: *(оставить поле пустым)*
3. **Схлопнуть несколько пустых строк подряд в одну пустую строку**:
   * Поиск: `\n\n+`
   * Замена: `\n\n`
4. **Обернуть все числа в квадратные скобки (`42` -> `[42]`)**:
   * Поиск: `\d+`
   * Замена: `[\0]`
5. **Заменить отступ из 4 пробелов/табов в начале строки на одну табуляцию** (а просто `^` добавит `\t` в начало всех строк):
   * Поиск: `^\s\s\s\s`
   * Замена: `\t`
6. **Разбить список через запятую на отдельные строки с отступом-табуляцией**:
   * Поиск: `,\s*`
   * Замена: `,\n\t`

## 6. Запись и управление макросами (`Ctrl+.` / `Ctrl+M`)

В редактор встроен полноценный рекордер клавиатурных макросов:
* **`Ctrl+.`** — начать / остановить запись последовательности нажатий (навигация, выделение, ввод текста, удаление, комментирование и т.д.). При остановке записи предлагается назначить имя и горячую клавишу (`Ctrl+<буква>` или `Alt+<буква>`).
* **`Ctrl+M`** — открыть менеджер сохранённых макросов: просмотр записанных шагов (`<C-Left>`, `<Sel-Word-R>`, `<Comment>`, `<Dup>` и др.), запуск выбранного макроса (`Enter`) или удаление (`F8` / `Del`).

## 7. Сохранение, авто-`sudo`, экран терминала и справка

* **`F2`** — сохранить файл. Если файл защищён от записи (`EACCES` / `EPERM`, например `/etc/...`), редактор автоматически выведет красный запрос пароля **`sudo`** и сохранит изменения через привилегированный помощник.
* **`Shift+F2`** — «Сохранить как...» (сохранение под новым именем с автоматическим переключением подсветки синтаксиса).
* **`Ctrl+O`** — переключиться на экран вывода терминала (как в FAR Manager) и вернуться обратно в редактор по повторному `Ctrl+O`.
* **`Hold Ctrl / Shift / Alt`** — динамическая подсказка клавиш `F1..F12` в нижней строке подсвечивает доступные комбинации с зажатым модификатором.
* **`F1`** — открыть встроенную интерактивную справку редактора с живым фильтром по клавишам.
* **`Esc` / `F10` / `Ctrl+Q`** — выйти из редактора (если есть несохранённые изменения — диалог `[ Yes ] / [ No ] / [ Cancel ]`).
